# Awesome Long-Horizon SWE

Project repository for **Long-Horizon Software Engineering Agents: From Tasks to Projects**.

**[Project website](https://longhorizonswe.github.io/)** · **[Website source](https://github.com/LongHorizonSWE/longhorizonswe.github.io)**

The project is being prepared. The website currently displays a coming-soon page; survey resources and website content will be added later.

## Repositories

- **[Awesome-LongHorizonSWE](https://github.com/LongHorizonSWE/Awesome-LongHorizonSWE)** is the main project repository.
- **[longhorizonswe.github.io](https://github.com/LongHorizonSWE/longhorizonswe.github.io)** contains the website and its automatic GitHub Pages deployment. Website changes are made there and published by pushing to `main`.

The manuscript, Overleaf sources, figures, and PDF are maintained separately.
